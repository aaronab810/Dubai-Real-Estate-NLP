# Manuscript and supporting material

**Online Property Discussion and Dubai Property Sales: An Auditable X–Reddit Study**

The manuscript presents the construction of an X–Reddit–DLD research dataset and an exploratory comparison of weekly discussion with property sales. Independent validation of the candidate SMDI categories remains pending.
