# **Dubai Real Estate NLP**



This repository contains the code, notebooks, and analysis developed for a research project investigating the use of Natural Language Processing (NLP) techniques to analyze social media discussions and market-related data within the Dubai real estate sector.



The project focuses on collecting and processing data from online platforms, performing sentiment analysis, topic discovery, and exploratory analytics to better understand public perceptions, trends, and discussions related to Dubai's real estate market.



##### **Research Objectives**

* Collect and preprocess real estate-related data from social media platforms.
* Analyze public sentiment using NLP techniques.
* Identify emerging themes and discussion topics.
* Highlight social media insights 
* Develop reproducible research workflows using Jupyter notebooks.
