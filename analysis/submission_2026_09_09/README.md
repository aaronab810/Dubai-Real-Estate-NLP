# Dubai discourse and registered property activity: reproduction bundle

The paper is `../../paper/main.tex`, bibliography `../../paper/references.bib`, and compiled output `../../paper/main.pdf`. It targets the current **ISDIA 2027** Springer LNNS call using the venue-supplied `svmult.cls`. This is an exploratory candidate-indicator study. No new semantic human labels, causal result, forecast evaluation or validated geolocation is claimed. See `CURRENT_DECISIONS.md` for the user's authorization to proceed without a new annotation round and the superseded temporary analysis hold.

## Reproduce

Run from repository root in PowerShell, using `analysis/refit_2026_09_07/.venv/Scripts/python.exe`. Dependencies are recorded in `requirements-lock.txt`; exact source/model/output hashes are in the JSON manifests and `artifact_hashes.json`. Inputs live in the existing source directories and `private/`; they are not included in the manuscript ZIP.

The computational dependency order is:

1. `build_corpus.py`, `build_dld.py`, `validate_upstream.py` — reconcile source records, historical quality labels, registration units and timestamps.
2. `verify_inputs.py`, `near_duplicates.py` — source-set checks and near-family sensitivity.
3. `fit_topics.py` — embeddings, six actual fits, linkage comparisons and native automatic reduction. Cached embeddings are reused only when training order agrees. A fresh invocation refits models; do not launch duplicate runs.
4. `freeze_analysis_corpus.py` — target-only v2 repairs following discovery inspection; preserve the v1 discovery model training population.
5. `assign_semantics.py` — versioned candidate cues and topic gates, labels and model sensitivities. It reads no DLD outcomes. `semantic_manifest.json` records its original freeze time.
6. `analyse_associations.py` — full finite exploratory association family and robustness. `--development-only` is retained as a compatibility flag; no human-label gate remains.
7. `spatial_feasibility.py`, `final_diagnostics.py`, `check_analysis.py` — literal geographic feasibility, final-subset diagnostics and numerical checks.
8. `prepare_validation.py` — optional blinded 300-record packets that exclude developer-inspected records. This supersedes the initial packet generated by the assignment script. Do not overwrite human-completed packets if supplied later.
9. `complete_bibliography.py`, `make_paper_assets.py` — verified references, editable tables and vector figures. The former uses cached DOI metadata where available.
10. Compile with the local compiler:

```powershell
$env:TECTONIC_CACHE_DIR = (Join-Path (Get-Location) 'analysis/submission_2026_09_09/tools/tex-cache')
& 'analysis/submission_2026_09_09/tools/tectonic.exe' -X compile paper/main.tex --keep-logs --keep-intermediates
```

Render and visually check every PDF page after manuscript edits. `paper/qa` holds local review renders and is excluded from the source ZIP.
